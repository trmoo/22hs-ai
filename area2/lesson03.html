1

분류 — 어느 칸에 넣을지 정하는 문제

1차시에서 배운 것처럼, 정답이 붙어 있는 데이터로 학습하는 방식을 지도학습이라고 합니다. 지도학습은 예측하려는 정답의 생김새에 따라 크게 두 갈래로 나뉩니다.

🗂️

분류 (classification)

정답이 범주입니다. 사과/감귤, 스팸/정상, 불량/양품처럼 정해진 칸 중 하나를 고릅니다. 결과에 “중간값”이 없습니다.

📈

회귀 (regression)

정답이 수치입니다. 내일 기온 24.7 ℃, 집값 3억 2천만 원처럼 연속된 값을 맞힙니다. 다음 4차시의 주제입니다.

즉 예측 결과가 범주이면 분류, 예측 결과가 수치이면 회귀입니다. “이 사진이 개인가 고양이인가”는 분류이고, “이 강아지의 몸무게는 몇 kg인가”는 회귀입니다. 같은 데이터로도 질문을 어떻게 세우느냐에 따라 문제 유형이 달라집니다.

📘 개념

분류는 새로운 데이터가 미리 정해진 여러 범주(클래스) 중 어디에 속하는지 예측하는 지도학습 문제이다. 클래스가 두 개면 이진 분류, 세 개 이상이면 다중 분류라고 한다.

분류 모델이 학습하는 것은 결국 속성 공간을 나누는 선입니다. 무게를 가로축, 껍질 거칠기를 세로축으로 놓고 데이터를 점으로 찍으면, 사과들이 모인 영역과 감귤들이 모인 영역이 생깁니다. 이 두 영역을 가르는 경계를 결정 경계라고 합니다.

결정 경계는 알고리즘마다 모양이 다릅니다. 어떤 알고리즘은 반듯한 직선을 긋고, 어떤 알고리즘은 구불구불한 곡선을 긋습니다. 이 차시의 시뮬레이터에서 여러분은 결정 경계가 눈앞에서 모양을 바꾸는 것을 직접 보게 됩니다.

2

k-최근접 이웃 — 가까운 이웃에게 물어본다

k-최근접 이웃(k-NN, k-Nearest Neighbor)은 이름이 원리를 그대로 말해 줍니다. 새 데이터가 들어오면 가장 가까운 이웃 k개를 찾고, 그 이웃들의 클래스를 세어 다수결로 예측합니다.

알고리즘 네 단계

  1. 새 데이터와 모든 훈련 데이터 사이의 거리를 계산한다.
  2. 거리가 가까운 순서로 정렬한다.
  3. 앞에서 k개를 뽑는다.
  4. 뽑힌 k개의 클래스를 세어 가장 많은 클래스로 예측한다.
📘 개념

k-최근접 이웃 알고리즘은 예측하려는 데이터에서 거리가 가장 가까운 k개의 훈련 데이터를 찾아, 그 k개의 클래스 중 다수의 클래스를 예측값으로 삼는 분류 알고리즘이다. 회귀에 쓸 때는 다수결 대신 k개 이웃의 평균값을 예측값으로 쓴다.

“가깝다”를 숫자로 바꾸기

k-NN의 모든 판단은 거리에서 나옵니다. 그래서 거리를 어떻게 재는지가 매우 중요합니다. 가장 많이 쓰는 두 가지는 다음과 같습니다.

속성이 두 개(x, y)일 때 두 점 P₁(x₁, y₁), P₂(x₂, y₂) 사이의 거리
거리계산식느낌
유클리드 거리 d = √{ (x₁−x₂)² + (y₁−y₂)² } 자로 잰 직선거리. 우리가 보통 말하는 거리.
맨해튼 거리 d = |x₁−x₂| + |y₁−y₂| 격자 도로를 따라간 블록 거리. 대각선으로 못 간다.

두 점의 좌표 차이를 제곱해 더한 뒤 제곱근을 씌우는 것이 유클리드 거리이고, 좌표 차이의 절댓값을 그대로 더하는 것이 맨해튼 거리입니다. 1단원 4차시의 A* 탐색에서 쓴 그 거리와 같은 개념입니다. 어느 것을 쓰느냐에 따라 “누가 이웃인지”가 달라지므로, 결정 경계의 모양도 달라집니다.

예) P₁(1, 2), P₂(4, 6) → 유클리드 = √(3² + 4²) = √25 = 5  /  맨해튼 = |3| + |4| = 7
🔍 속성이 세 개 이상이면?

식이 그대로 늘어납니다. 속성이 n개면 d = √{ (a₁−b₁)² + (a₂−b₂)² + … + (aₙ−bₙ)² }입니다. 우리 눈에는 3차원까지만 그려지지만, 컴퓨터는 속성이 100개여도 같은 식으로 거리를 계산합니다.

3

k값과 정규화 — 성능을 좌우하는 두 가지

k-NN에는 학습으로 정해지는 값이 없습니다. 대신 사람이 정해 주어야 하는 값이 있습니다. 바로 이웃을 몇 개 볼지를 정하는 k입니다. 이렇게 사람이 미리 정해 주는 값을 하이퍼파라미터라고 부릅니다.

k가 작을 때와 클 때

k = 1이면 가장 가까운 한 점이 모든 것을 결정합니다. 그 한 점이 잘못 측정된 값이거나 예외적인 데이터라면 예측도 함께 틀립니다. 훈련 데이터는 100% 맞히지만 새 데이터에서는 흔들리는 이 현상을 과대적합이라고 합니다.

반대로 k를 아주 크게 잡으면 멀리 있는 이웃까지 표를 던집니다. 극단적으로 k를 전체 데이터 개수만큼 잡으면, 어디를 물어봐도 가장 개수가 많은 클래스가 나옵니다. 경계가 뭉개져 데이터의 실제 구조를 담지 못하는 이 현상을 과소적합이라고 합니다.

k값이 만드는 차이
구분k가 작다 (예: 1)k가 크다 (예: 전체의 절반)
결정 경계구불구불하고 섬이 생긴다부드럽고 단순해진다
잡음에 대한 반응한 점에도 크게 흔들린다거의 흔들리지 않는다
훈련 데이터 정확도매우 높다(k=1이면 100%)낮아진다
새 데이터 정확도낮아질 수 있다(과대적합)낮아질 수 있다(과소적합)
계산량같다같다
⚠️ k는 왜 홀수로 두나요?

클래스가 두 개인데 k = 4라면 2 대 2로 동점이 날 수 있습니다. 동점이면 다수결이 성립하지 않아 억지로 규칙을 하나 더 만들어야 합니다. 그래서 이진 분류에서는 k를 홀수로 두는 것이 관례입니다. 다만 클래스가 세 개 이상이면 홀수여도 동점이 날 수 있습니다(예: 3개 클래스에 k = 3이 1:1:1).

정규화 — 단위가 큰 속성이 거리를 독차지한다

2차시에서 배운 정규화가 k-NN에서 특히 중요합니다. 이유는 간단합니다. k-NN은 거리로만 판단하는데, 값의 범위가 큰 속성이 거리 계산을 사실상 독차지해 버리기 때문입니다.

예를 들어 연 수입(2,000~8,000만 원)과 자녀 수(0~4명)로 사람을 분류한다고 해 봅시다. 수입 차이는 수천 단위로 벌어지고 자녀 수 차이는 최대 4입니다. 제곱해 더하면 자녀 수는 있으나 마나 한 값이 됩니다. 자녀 수가 실제로는 결정적인 속성이어도 모델은 그것을 완전히 무시합니다.

정규화 전: d = √{ (3200−3300)² + (4−0)² } = √(10000 + 16) ≈ 100.08  ← 자녀 수 4명 차이가 사실상 사라진다

최소-최대 정규화를 하면 모든 속성이 0~1 범위로 바뀌어 동등한 발언권을 갖습니다. 아래 두 번째 시뮬레이터에서 정규화를 껐다 켰다 하며 예측이 실제로 뒤바뀌는 것을 확인해 보세요.

✅ 꼭 지킬 것

정규화에 쓰는 최솟값·최댓값은 훈련 데이터에서 구하고, 새로 들어온 데이터에도 같은 기준을 적용해야 한다. 새 데이터마다 기준을 다시 만들면 같은 값이 매번 다르게 변환되어 모델이 엉뚱한 판단을 하게 된다.

4

게으른 학습, 그리고 다른 분류 알고리즘들

대부분의 기계학습 모델은 훈련 단계에서 열심히 계산해 규칙(가중치)을 만들어 두고, 예측할 때는 그 규칙에 값을 넣기만 합니다. 그런데 k-NN은 정반대입니다. 훈련 단계에서 하는 일이 데이터를 그냥 저장하는 것뿐입니다.

모든 계산은 예측할 때 몰아서 일어납니다. 새 데이터가 들어오면 그때야 저장해 둔 모든 데이터와 거리를 계산합니다. 이렇게 학습을 예측 시점까지 미루는 방식을 게으른 학습이라고 부릅니다. 반대로 미리 규칙을 만들어 두는 방식은 부지런한 학습(eager learning)이라고 합니다.

🔍 게으른 학습의 대가

훈련 시간이 거의 0이라는 장점 뒤에는 대가가 있습니다. 훈련 데이터가 10만 개라면 예측 한 번마다 10만 번의 거리 계산이 필요합니다. 데이터 전체를 계속 메모리에 들고 있어야 하고, 예측이 느립니다. 실제로는 KD-트리 같은 자료구조로 탐색 범위를 줄여 속도를 높입니다.

k-최근접 이웃의 장점과 단점
장점단점
원리가 단순해 이해하고 설명하기 쉽다 예측할 때마다 모든 데이터와 거리를 계산해 느리다
훈련 시간이 거의 들지 않는다 데이터 전체를 저장해야 해 메모리를 많이 쓴다
경계가 복잡한 데이터에도 잘 맞는다 정규화를 하지 않으면 성능이 크게 떨어진다
데이터를 추가하면 바로 반영된다 속성이 많아지면 거리 개념이 흐려진다(차원의 저주)

분류에 쓰이는 다른 알고리즘

분류 문제를 푸는 알고리즘은 k-NN 말고도 많습니다. 문제의 성격과 데이터의 모양에 따라 잘 맞는 알고리즘이 달라지므로, 여러 개를 돌려 보고 성능을 비교하는 것이 일반적입니다.

심화 거리로 가중치를 주면 더 좋아질까 — 가중 k-NN

기본 k-NN에서는 이웃 k개가 모두 한 표씩 행사합니다. 그런데 코앞에 붙어 있는 이웃과 저 멀리 걸쳐 있는 이웃이 같은 힘을 갖는 것은 좀 이상합니다.

가중 k-NN은 거리 d에 반비례하는 가중치(예: 1/d 또는 1/d²)를 주어 가까운 이웃의 표를 더 무겁게 셉니다. 이렇게 하면 k를 크게 잡아도 경계가 지나치게 뭉개지지 않고, 동점 문제도 자연스럽게 줄어듭니다.

또 하나 알아 둘 개념은 차원의 저주입니다. 속성이 많아질수록 데이터들이 서로 멀어져, 가장 가까운 이웃과 가장 먼 이웃의 거리 차이가 줄어듭니다. “가깝다”는 말이 의미를 잃는 것이죠. 그래서 속성이 많을 때는 핵심 속성만 골라내는 속성 추출(2차시)이 더욱 중요해집니다.

코드 파이썬으로 쓴 k-NN — 열 줄이면 끝난다

왼쪽은 원리를 그대로 옮긴 코드, 오른쪽은 사이킷런을 쓴 코드입니다. 하는 일은 같습니다.

원리 그대로사이킷런
 
from collections import Counter
import math

def knn(train, labels, new, k=3):
    ds = []
    for x, y in zip(train, labels):
        d = math.dist(x, new)   # 유클리드
        ds.append((d, y))
    ds.sort()                   # 가까운 순
    near = [y for d, y in ds[:k]]
    return Counter(near).most_common(1)[0][0]
 
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import MinMaxScaler

sc = MinMaxScaler()             # 정규화 필수!
X_train = sc.fit_transform(X_train)
X_test  = sc.transform(X_test)  # 같은 기준

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)     # 저장만 한다
print(model.score(X_test, y_test))

오른쪽에서 fit_transform은 훈련 데이터로 최솟값·최댓값을 정하고 변환하지만, transform은 이미 정해진 기준으로만 변환합니다. 이것이 앞에서 강조한 “같은 기준”입니다.

사례 여러분이 매일 쓰고 있는 k-NN

음악·영상 추천이 대표적입니다. “나와 취향이 비슷한 사용자들”을 거리로 찾아 그들이 좋아한 곡을 추천하는 방식을 협업 필터링이라고 하는데, 그 뼈대가 최근접 이웃입니다.

손글씨 숫자 인식도 초기에는 k-NN으로 풀었습니다. 28×28 픽셀을 784개 속성으로 보고 가장 비슷한 숫자 이미지 k개를 찾는 것이죠. 단순한데도 정확도가 95%를 넘습니다.

이상 거래 탐지에서는 반대로 씁니다. 새 결제가 이웃들과 지나치게 멀면 이상치로 의심합니다. 거리가 크다는 것 자체가 신호가 되는 셈입니다.

연결 다음 차시로 — 범주가 아니라 숫자를 맞혀야 한다면
이 차시에서는 “사과냐 감귤이냐”를 정했습니다. 그런데 “이 학생은 몇 점을 받을까”처럼 숫자를 맞혀야 하는 문제라면 다수결로는 답이 나오지 않습니다. 다음 4차시에서는 데이터 사이로 선 하나를 그어 수치를 예측하는 회귀를 배우고, 그 선을 컴퓨터가 스스로 찾아가는 경사 하강법을 눈으로 확인합니다.
