🤔 돌아보며 열기

2단원에서 우리는 일곱 차시 동안 데이터를 만지고, 선을 긋고, 점을 묶고, 층을 쌓았습니다. 그런데 이 모든 활동에서 딱 한 문장만 남긴다면 무엇일까요?

“규칙을 짜지 않고, 데이터로 규칙을 찾아내게 한다.”

이 문장이 전부입니다. 그리고 이 한 문장에서 나머지 모든 개념이 따라 나옵니다. 데이터가 지저분하면 규칙도 엉망이 되니 전처리가 필요하고, 찾아낸 규칙이 정말 쓸 만한지 확인해야 하니 평가가 필요하고, 규칙이 너무 복잡한 문제라면 층을 깊게 쌓는 딥러닝이 필요해집니다.

힌트 일곱 차시를 순서로 이어 보기
기계학습으로 풀 문제를 정하고 데이터를 모은다(1차시) → 데이터를 다듬고 속성을 뽑는다(2차시) → 문제에 맞는 알고리즘을 고른다(3·4·5차시) → 훈련 데이터로 학습하고 테스트 데이터로 평가한다(6차시) → 더 복잡한 문제는 층을 깊게 쌓아 푼다(7차시). 이 흐름이 곧 아래의 개념 지도입니다.
1

한 장으로 보는 2단원 개념 지도

1~7차시

2단원의 개념 지도는 파이프라인 모양입니다. 데이터가 왼쪽에서 들어와 여러 단계를 거쳐 모델이 되고, 평가 결과가 나쁘면 주황색 점선을 따라 앞 단계로 되돌아갑니다. 이 되돌아가는 화살표가 2단원의 진짜 주인공입니다.

🧭 지도를 읽는 세 가지 방법
  • 왼쪽에서 오른쪽으로 — 데이터가 모델이 되는 순서입니다. 어느 한 단계를 건너뛰면 뒤의 모든 단계가 흔들립니다. 특히 데이터 가공을 건너뛰면 뒤에서 어떤 알고리즘을 써도 성능이 나오지 않습니다.
  • 가운데 세 갈래를 비교 — 갈림길의 기준은 딱 하나, 정답(라벨)이 데이터에 붙어 있는가입니다. 붙어 있으면 지도학습(분류·회귀), 없으면 비지도학습(군집)입니다.
  • 주황색 점선을 따라 거꾸로 — 기계학습은 한 번에 끝나지 않습니다. 평가해 보고 되돌아가서 데이터와 속성을 고치는 반복이 정상입니다. 4단원의 프로젝트가 이 점선을 그대로 실행합니다.
2

차시별 핵심 정리

마지막 열은 실제로 학생들이 가장 많이 틀리는 지점만 모은 것입니다. 이 열부터 읽어도 좋습니다.

2단원 인공지능과 학습 — 차시별 정리
차시꼭 알아야 할 개념한 줄 요약자주 나오는 오해
1차시
규칙을 짜지 않고 가르치기		 기계학습, 지도학습·비지도학습·강화학습, 문제 정의, 데이터 선정 사람이 규칙을 적는 대신, 데이터에서 규칙을 찾아내게 하는 것이 기계학습이다. “데이터가 많으면 무조건 잘된다” → 문제와 관련 있는 데이터여야 합니다. 관련 없는 데이터를 아무리 쌓아도 성능은 오르지 않습니다.
2차시
데이터를 다듬다		 결측치, 이상치, 정규화, 핵심 속성 추출 모델의 성능은 알고리즘보다 데이터의 상태에서 먼저 갈린다. “이상치는 무조건 지운다” → 이상치가 중요한 신호일 수 있습니다(불량, 사기, 이상 징후). 지울지 살릴지는 문제에 따라 판단합니다.
3차시
이웃에게 물어보기		 분류, k-NN, 결정 경계, k 값의 영향, 거리 계산 k-NN 은 학습이라기보다 기억이다. 새 점이 오면 가장 가까운 k 개의 이웃에게 투표를 맡긴다. “k 는 클수록 정확하다” → k 가 너무 작으면 잡음에 흔들리고, 너무 크면 경계가 뭉개져 소수 집단을 놓칩니다. 적절한 k 는 실험으로 찾습니다.
4차시
선 하나로 예측하기		 회귀, 오차 제곱의 합, 경사 하강법, 학습률 오차를 가장 작게 만드는 방향으로 조금씩 내려가며 선의 기울기와 절편을 고쳐 나간다. “학습률은 클수록 빨리 배운다” → 너무 크면 최솟값을 지나쳐 튕겨 나가 오차가 오히려 커집니다. 너무 작으면 너무 느립니다.
5차시
정답 없이 묶기		 비지도학습, 군집, k-평균, 중심 이동 반복 중심을 정하고 → 가까운 점을 모으고 → 중심을 다시 계산하는 일을 중심이 움직이지 않을 때까지 반복한다. “군집도 정답을 맞히는 것이다” → 군집에는 정답이 없습니다. 나온 군집의 의미는 사람이 해석해서 붙입니다. 시작 중심에 따라 결과가 달라질 수도 있습니다.
6차시
얼마나 잘 맞혔나		 훈련·테스트 데이터 분리, 혼동 행렬, 정확도, 정밀도, 재현율, 과대적합 훈련 데이터 점수는 성적표가 아니다. 본 적 없는 데이터에서의 점수만이 성능이다. “정확도가 높으면 좋은 모델이다” → 100명 중 환자가 1명뿐인 데이터에서 전부 정상이라고 답해도 정확도는 99%입니다. 이럴 때는 정밀도와 재현율을 봐야 합니다.
7차시
층을 쌓아 깊어지다		 퍼셉트론, 가중치, 활성화 함수, 은닉층, 인공신경망, 딥러닝 퍼셉트론 하나로는 직선 하나밖에 못 긋지만, 층을 쌓으면 휘어진 경계도 만들 수 있다. “딥러닝은 인공신경망과 다른 기술이다” → 딥러닝은 은닉층이 여러 층인 인공신경망을 학습시키는 것입니다. 다른 기술이 아니라 같은 계열의 깊어진 형태입니다.
🧮

혼동 행렬 네 칸 읽기

앞자리는 맞혔는가(T/F), 뒷자리는 무엇이라고 예측했는가(P/N)입니다. 그래서 FN 은 “양성인데 음성이라고 잘못 답한 것”입니다. 놓친 환자가 여기에 들어갑니다.

정밀도와 재현율의 맞바꿈

판정 임계값을 낮추면 양성이라고 더 많이 외치므로 재현율은 오르고 정밀도는 내려갑니다. 둘을 동시에 올리기는 어려워서, 무엇이 더 중요한 상황인지 정해야 합니다.

과대적합의 신호

훈련 오차는 계속 줄어드는데 테스트 오차가 어느 지점부터 다시 커지면 과대적합입니다. 모델을 단순하게 만들거나 데이터를 늘리는 것이 대처법입니다.

핵심 용어 빈칸 점검

본문 빈칸 14개

아래 다섯 문단은 2단원 전체를 압축한 요약입니다. 위쪽의 빈칸 채우기 모드를 켜고 채워 보세요. 용어를 눈으로만 읽는 것과 손으로 쓰는 것은 전혀 다릅니다.

① 규칙 대신 데이터

사람이 조건을 하나하나 적어 주는 대신, 데이터에서 규칙(모델)을 스스로 찾아내게 하는 방법을 기계학습이라고 합니다. 정답(라벨)이 붙은 데이터로 학습하는 유형을 지도학습, 정답 없이 데이터의 구조를 찾아내는 유형을 비지도학습이라고 하며, 보상을 통해 행동을 개선해 가는 유형은 강화학습입니다.

② 데이터를 다듬는 일

현실의 데이터는 비어 있거나 잘못된 값이 섞여 있습니다. 값이 아예 비어 있는 칸을 결측치라고 하며, 평균이나 중앙값으로 채우거나 해당 행을 지웁니다. 다른 값들과 크게 동떨어진 값은 이상치라고 하는데, 잡음일 수도 있지만 오히려 찾아야 할 신호일 수도 있으므로 문제에 따라 판단합니다. 또 키(cm)와 몸무게(kg)처럼 단위와 범위가 다른 속성을 함께 쓸 때는 값의 범위를 일정하게 맞추는 정규화가 필요합니다.

③ 문제에 맞는 알고리즘 고르기

지도학습은 예측하려는 값이 어떤 종류인가에 따라 둘로 나뉩니다. 합격과 불합격처럼 정해진 몇 가지 중 하나를 고르는 문제는 분류이고, 키에 따른 몸무게처럼 연속적인 수를 예측하는 문제는 회귀입니다. 회귀에서는 예측값과 실제값의 오차 제곱의 합을 가장 작게 만들어야 하는데, 오차가 줄어드는 방향으로 조금씩 내려가며 기울기와 절편을 고치는 방법을 경사 하강법이라고 합니다. 한편 정답이 없는 데이터를 비슷한 것끼리 묶는 일은 군집이라고 하며, k-평균 알고리즘이 대표적입니다.

④ 성능을 정직하게 재기

모델을 평가할 때는 데이터를 나누어, 학습에는 훈련 데이터만 쓰고 성능 측정에는 학습에 쓰지 않은 테스트 데이터를 씁니다. 분류 모델의 예측 결과를 실제 값과 맞대어 네 칸으로 정리한 표를 혼동 행렬이라고 합니다. 이 표에서 모델이 양성이라고 예측한 것 중 실제로 양성인 비율이 정밀도이고, 실제 양성 중에서 모델이 양성이라고 찾아낸 비율이 재현율입니다. 훈련 데이터에는 잘 맞지만 새로운 데이터에서 성능이 떨어지는 현상은 과대적합입니다.

⑤ 층을 쌓아 깊어지기

사람의 신경세포를 본떠 여러 입력에 가중치를 곱해 더한 뒤 활성화 함수를 통과시켜 출력을 내는 가장 단순한 모형을 퍼셉트론이라고 합니다. 퍼셉트론 하나는 직선 하나만 그을 수 있어 XOR 같은 문제를 풀지 못하는데, 입력층과 출력층 사이에 은닉층을 넣으면 휘어진 경계도 만들 수 있습니다. 이렇게 은닉층이 여러 층인 인공신경망을 학습시키는 것을 딥러닝이라고 하며, 영상·음성·언어처럼 사람이 규칙을 적기 어려운 분야에서 특히 뛰어난 성능을 보입니다.

⚠️ 여기서 헷갈리면 반드시 다시 보기

분류와 군집은 겉모습이 비슷해 보이지만 완전히 다릅니다. 분류는 정답이 있는 데이터로 배워 새 데이터의 정답을 맞히는 지도학습이고, 군집은 정답이 없는 데이터를 비슷한 것끼리 모으는 비지도학습입니다. “미리 정해진 이름표가 있는가”를 물어보면 바로 구별됩니다.

서·논술형 문항

정답이 하나가 아닌 문항입니다. 각 문항의 평가 기준을 먼저 펼쳐 보고, 그 요소들이 내 글에 들어 있는지 확인하며 쓰세요.

문항 1 · 서술형

어떤 학생이 만든 모델은 훈련 데이터에서 정확도 99%인데 테스트 데이터에서는 62%였습니다. 이 현상의 이름과 원인을 밝히고, 이 학생이 시도해 볼 수 있는 개선 방법을 두 가지 이상 제안하시오.

평가 기준 좋은 답에 반드시 들어가야 할 요소
  • 현상의 이름을 정확히 썼는가 — 과대적합.
  • 원인을 모델이 데이터의 규칙이 아니라 훈련 데이터 자체를 외운 것으로 설명했는가.
  • 훈련 오차와 테스트 오차의 움직임 차이로 근거를 댔는가.
  • 개선 방법을 두 가지 이상 구체적으로 제시했는가 — 모델을 단순하게(속성 수 줄이기, 신경망 층·노드 줄이기), 데이터를 늘리기, 데이터 분할 방식 점검, 학습을 일찍 멈추기 등.
  • “테스트 데이터를 학습에 절대 쓰지 않는다”는 원칙을 언급하면 매우 우수한 답입니다.
문항 2 · 설계형

우리 학교나 일상에서 기계학습으로 풀고 싶은 문제를 하나 정하시오. 그 문제에 필요한 데이터와 속성, 학습 유형(지도학습·비지도학습), 알고리즘, 성능 평가 방법을 순서대로 설계하시오.

평가 기준 좋은 답에 반드시 들어가야 할 요소
  • 문제가 예측·분류·군집 중 무엇인지 분명한가(“도서관을 개선하겠다”는 문제 정의가 아닙니다).
  • 필요한 데이터의 출처와 개수, 그리고 속성 목록을 적었는가.
  • 정답(라벨)이 있는지 여부를 근거로 학습 유형을 선택했는가.
  • 선택한 알고리즘이 문제 유형과 맞는가(분류에 선형 회귀를 쓰는 식의 불일치가 없는가).
  • 평가 지표를 정하고 왜 그 지표인지 밝혔는가. 데이터가 한쪽으로 치우쳤다면 정확도만 쓰지 않았는가.
  • 전처리 계획(결측치·이상치·정규화)을 한 줄이라도 포함했는가.
문항 3 · 논술형

다음 두 상황에서 정밀도와 재현율 중 무엇을 더 중요하게 볼 것인지 각각 정하고, 그 이유를 잘못된 판정이 만드는 실제 피해와 연결해 논술하시오.
(가) 학교 급식실의 식중독 위험 식재료 판별  ·  (나) 학생 휴대전화의 스팸 문자 자동 차단

평가 기준 좋은 답에 반드시 들어가야 할 요소
  • 두 지표의 정의를 혼동 행렬의 칸과 연결해 정확히 썼는가(정밀도는 FP 를 줄이는 데, 재현율은 FN 을 줄이는 데 중점).
  • (가)에서 FN(위험한데 안전하다고 판정)의 피해가 훨씬 크므로 재현율을 중시한다고 판단했는가.
  • (나)에서 FP(중요한 문자를 스팸으로 차단)의 피해를 근거로 정밀도를 중시한다고 판단했는가.
  • 두 지표가 서로 맞바뀌는 관계임을 언급했는가(임계값을 낮추면 재현율↑ 정밀도↓).
  • 정확도만으로 판단하면 안 되는 이유를 데이터 불균형과 연결했다면 매우 우수한 답입니다.

🚪 3단원으로 가는 문

2단원에서 우리는 성능을 올리는 방법을 배웠습니다. 그런데 여기서 한 가지 질문이 남습니다. “성능이 높으면 좋은 인공지능인가?”

합격자를 예측하는 모델을 과거 합격 데이터로 학습시켰다고 해 봅시다. 과거에 특정 집단이 불리했다면, 모델은 그 불리함까지 함께 배워 정확도 높게 재현합니다. 데이터가 편향되면 모델도 편향됩니다. 성능 지표는 이 문제를 잡아내지 못합니다.

3단원 인공지능의 사회적 영향에서는 인공지능이 바꾸는 사회와 직업, 그리고 편향·프라이버시·책임의 문제를 다룹니다. 2단원이 “어떻게 만드는가”였다면, 3단원은 “만들어도 되는가, 어떻게 써야 하는가”입니다.

심화 정확도의 함정을 숫자로 확인하기

어떤 희귀병의 유병률이 1%라고 합시다. 검사를 아무것도 하지 않고 모든 사람에게 “정상”이라고만 답하는 모델을 만들면 정확도는 얼마일까요?

1000명 중 환자 10명, 정상 990명입니다. 전부 정상이라고 답하면 990명을 맞히므로 정확도는 99%입니다. 그런데 이 모델의 재현율은 0/10 = 0%이고 정밀도는 계산조차 되지 않습니다(양성 예측이 하나도 없음).

그래서 데이터가 한쪽으로 치우친 문제에서는 정확도를 성능 지표로 쓰면 안 됩니다. 혼동 행렬을 그려 네 칸을 직접 보는 습관이 이 함정을 막아 줍니다.

코드 파이프라인 전체를 열 줄로 쓰기

개념 지도의 흐름을 그대로 코드로 옮기면 이렇게 됩니다. 각 줄이 어느 차시에 해당하는지 확인해 보세요.

df = load('students.csv')                     # 1차시 데이터 수집
df = df.dropna()                              # 2차시 결측치 처리
df = remove_outliers(df, 'study_hours')       # 2차시 이상치 처리
X = normalize(df[['study_hours', 'sleep']])   # 2차시 정규화 · 속성 추출
y = df['pass']                                # 정답(라벨)

X_train, X_test, y_train, y_test = split(X, y, test_ratio=0.2)   # 6차시 데이터 분리

model = KNN(k=5)                              # 3차시 알고리즘 선정
model.fit(X_train, y_train)                   # 학습은 훈련 데이터로만

pred = model.predict(X_test)                  # 6차시 평가는 테스트 데이터로
print(confusion_matrix(y_test, pred))         # 혼동 행렬 확인

주목할 점은 split 이 fit 보다 먼저 나온다는 것입니다. 순서를 바꾸면 테스트 데이터가 학습에 섞여 들어가 성능이 부풀려집니다.

사례 이 단원의 개념이 실제로 쓰이는 곳
  • 병원의 영상 판독 보조 — 딥러닝으로 사진에서 이상 부위를 찾습니다. 놓치면 위험하므로 재현율을 특히 중요하게 봅니다.
  • 공장 불량 검사 — 정상 제품이 압도적으로 많은 불균형 데이터입니다. 그래서 정확도보다 혼동 행렬 전체를 봅니다.
  • 온라인 상점의 고객 묶음 — 정답이 없는 구매 기록을 k-평균으로 묶어 비슷한 취향의 집단을 찾고, 사람이 그 집단의 의미를 해석합니다.
  • 기상 예측 보정 — 관측값과 예측값의 오차를 줄이는 회귀 모델을 학습시켜 예보를 보정합니다.
  • 음성 비서 — 소리 파형을 문자로 바꾸는 일은 규칙으로 적기 불가능해, 대량의 음성 데이터로 학습한 딥러닝 모델이 담당합니다.
