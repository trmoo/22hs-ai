공부 시간(시간)135796
수학 점수3849637992?

공부 시간이 6시간인 친구의 점수는 몇 점쯤일까요? 지난 차시의 k-최근접 이웃이라면 “가까운 이웃 몇 명의 점수를 평균”하겠지만, 여기서는 다른 길로 가 봅시다.

숫자들을 보면 시간이 1시간 늘 때마다 점수가 대략 7점쯤 오르는 규칙이 보입니다. 이 규칙을 선 하나로 표현할 수 있다면, 표에 없는 시간에 대해서도 점수를 계산할 수 있습니다.

힌트 그 “선”을 어떻게 정할까요?
연필로 대충 그으면 사람마다 다른 선이 나옵니다. 컴퓨터는 “모든 점에서 선까지의 어긋남을 다 합쳤을 때 가장 작아지는 선”을 답으로 정합니다. 이 어긋남을 재는 방법과, 가장 작은 값을 찾아가는 방법이 이 차시의 핵심입니다.
1

범주가 아니라 숫자를 맞히는 문제

지난 차시의 분류는 “사과냐 감귤이냐”처럼 정해진 칸 중 하나를 골랐습니다. 그런데 “이 집은 얼마에 팔릴까”, “내일 몇 도일까”, “이 학생은 몇 점을 받을까”는 칸이 없습니다. 답이 연속된 수치이기 때문입니다. 이런 문제를 회귀라고 합니다.

주의할 점이 하나 있습니다. 3차시에서 배운 로지스틱 회귀는 이름에 회귀가 들어가지만 실제로는 분류 알고리즘입니다. 이름만으로 유형을 판단하면 안 됩니다.

🔍 순서가 있는 범주는 어느 쪽?

“상·중·하” 같은 등급은 범주이므로 분류입니다. 하지만 “1점~5점 별점”은 상황에 따라 회귀로 다루기도 합니다. 4.3점 같은 중간값이 의미를 가지면 회귀, “딱 별 4개”만 존재한다면 분류로 보는 것이 자연스럽습니다. 문제를 어떻게 정의하느냐가 유형을 결정합니다.

2

선형 회귀 — 직선 하나가 모델이다

가장 단순한 회귀 모델은 직선입니다. 입력 x 하나로 출력 y를 예측하는 단순 선형 회귀의 식은 다음과 같습니다.

ŷ = wx + b　　( ŷ : 예측값, x : 입력 속성, w : 가중치, b : 절편 )

여기서 x는 우리가 넣는 값(공부 시간)이고 ŷ는 모델이 내놓는 값(예상 점수)입니다. 모델이 학습으로 찾아야 하는 것은 오직 두 숫자, w와 b입니다. 이렇게 학습으로 값이 정해지는 숫자를 매개변수(파라미터)라고 부릅니다.

📐

w — 가중치(기울기)

x가 1 늘어날 때 ŷ가 얼마나 변하는가를 뜻합니다. w = 7이면 “한 시간 더 공부하면 7점 오른다”는 의미입니다. 통계에서는 회귀계수라고도 합니다.

🎚️

b — 절편

x가 0일 때의 예측값, 즉 출발점의 높이입니다. 직선을 위아래로 평행 이동시키는 역할을 합니다.

x가 1 커질 때 ŷ가 변하는 양을 나타내는 것이 가중치이고, x가 0일 때의 예측값을 절편이라고 합니다. 예측에 쓰는 입력 속성을 독립 변수, 예측하려는 값을 종속 변수라고 부릅니다.

📘 개념

선형 회귀는 독립 변수와 종속 변수의 관계를 직선(또는 평면)으로 나타내어 수치를 예측하는 지도학습 알고리즘이다. 학습이란 데이터에 가장 잘 맞는 가중치 w와 절편 b를 찾는 일이다.

3

“가장 잘 맞는 선”을 숫자로 정의하기

“잘 맞는다”는 느낌만으로는 컴퓨터가 계산할 수 없습니다. 먼저 얼마나 안 맞는지를 숫자로 재야 합니다. 실제로 관측된 값을 실젯값(y), 모델이 계산한 값을 예측값(ŷ)이라고 할 때, 그 차이를 오차라고 합니다. 그래프에서는 점에서 직선까지의 세로 거리로 보입니다.

그런데 오차를 그냥 다 더하면 큰 문제가 생깁니다. 어떤 점은 선 위에 있어 오차가 +10이고 어떤 점은 아래에 있어 −10이면, 둘을 더하면 0이 되어 “완벽한 모델”처럼 보입니다. 부호가 서로 상쇄되기 때문입니다.

그래서 오차를 제곱해서 더합니다. 제곱하면 부호가 사라지고, 덤으로 큰 오차에 더 큰 벌점이 붙습니다. 오차 2는 4가 되지만 오차 10은 100이 되니까요. 이렇게 오차를 제곱해 평균한 값이 평균 제곱 오차(MSE)입니다.

MSE = (1/n) × Σ ( yᵢ − ŷᵢ )²　　= (1/n) × { (y₁−ŷ₁)² + (y₂−ŷ₂)² + … + (yₙ−ŷₙ)² }
📘 개념

모델의 예측이 실젯값과 얼마나 어긋나는지를 하나의 수로 나타내는 함수를 오차 함수(손실 함수, 비용 함수)라고 한다. 회귀에서 가장 널리 쓰이는 오차 함수가 평균 제곱 오차(MSE)이며, 이 값이 작을수록 모델의 성능이 좋다.

⚠️ 왜 굳이 제곱인가 — 세 가지 이유
  • 부호 상쇄를 막는다. +와 −가 서로 지워지지 않습니다.
  • 큰 오차를 강하게 벌한다. 크게 틀린 점을 먼저 고치도록 모델을 밀어붙입니다.
  • 미분이 매끄럽다. 절댓값 함수는 꼭짓점에서 뾰족해 미분이 안 되지만, 제곱은 어디서나 매끄럽게 미분됩니다. 뒤에 나올 경사 하강법이 바로 이 성질을 씁니다.

다른 오차 함수도 있습니다. 오차의 절댓값을 평균한 MAE(평균 절대 오차)는 이상치에 덜 흔들리고, MSE에 제곱근을 씌운 RMSE(평균 제곱근 오차)는 단위가 원래 값과 같아 해석하기 쉽습니다.

최소 제곱법 — 공식으로 단번에 구하기

단순 선형 회귀에서는 MSE를 가장 작게 만드는 w와 b를 공식으로 한 번에 구할 수 있습니다. MSE를 w와 b에 대해 미분해 0이 되는 지점을 풀면 다음 식이 나옵니다. 이 방법을 최소 제곱법이라고 합니다.

w = Σ(xᵢ − x̄)(yᵢ − ȳ) ⁄ Σ(xᵢ − x̄)²　　　b = ȳ − w·x̄　　( x̄, ȳ 는 평균 )

공식으로 답이 나온다면 왜 굳이 다른 방법이 필요할까요? 속성이 수십만 개인 문제나 인공신경망처럼 매개변수가 수백만 개인 모델에서는 이런 공식을 풀 수 없기 때문입니다. 그래서 실제 기계학습은 다음 절의 방법을 씁니다.

결정계수 R² — 이 모델은 쓸 만한가

MSE는 단위에 따라 값이 커지므로 “0.8이면 좋은 건가”를 판단하기 어렵습니다. 그래서 0~1 사이의 값으로 모델의 설명력을 나타내는 결정계수(R²)를 함께 봅니다.

R² = 1 − ( Σ(yᵢ − ŷᵢ)² ⁄ Σ(yᵢ − ȳ)² )　　( 분모는 "그냥 평균으로 예측했을 때"의 오차 )

분모는 아무 노력 없이 평균값만 답하는 모델의 오차입니다. 그러니 R²는 “평균만 답하는 것보다 얼마나 나아졌는가”를 뜻합니다. R²가 1에 가까우면 데이터를 매우 잘 설명하는 것이고, 0이면 평균만 답하는 것과 다를 바 없습니다.

직선을 넘어서

입력 속성이 여러 개면 ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b 형태가 되고, 이를 다중 선형 회귀라고 합니다. 관계가 휘어 있을 때는 x², x³ 같은 항을 넣어 곡선을 만드는 다항 회귀를 씁니다. 다만 차수를 지나치게 높이면 모든 점을 억지로 지나가려다 과대적합에 빠집니다.

4

경사 하강법 — 더듬어서 내려가기

안개가 자욱한 산에 서 있다고 상상해 봅시다. 목표는 가장 낮은 곳으로 내려가는 것인데, 앞이 보이지 않습니다. 할 수 있는 일은 발밑의 기울기를 느끼고, 가장 급하게 내려가는 방향으로 한 걸음 옮기는 것뿐입니다. 이것을 계속 반복하면 결국 골짜기에 도달합니다.

기계학습이 오차를 줄이는 방식이 정확히 이렇습니다. w와 b를 조금씩 바꿔 가며 오차가 줄어드는 방향으로 옮기는 방법을 경사 하강법이라고 합니다.

📘 개념

경사 하강법은 오차 함수를 매개변수에 대해 미분해 얻은 기울기의 반대 방향으로 매개변수를 조금씩 이동시켜, 오차가 최소가 되는 값을 찾아가는 최적화 방법이다.

한 걸음의 계산

MSE를 w와 b에 대해 각각 미분하면 다음과 같습니다. 오차가 큰 점이, 그리고 x가 큰 점이 w를 더 강하게 끌어당긴다는 것을 식에서 읽을 수 있습니다.

∂MSE/∂w = (2/n) Σ ( ŷᵢ − yᵢ ) xᵢ　　　∂MSE/∂b = (2/n) Σ ( ŷᵢ − yᵢ )
w ← w − η × ∂MSE/∂w　　　b ← b − η × ∂MSE/∂b　　( η : 학습률 )

기울기 앞에 붙은 η가 한 걸음의 크기를 정하는 학습률입니다. 기울기의 반대 방향(빼기)으로 가는 것이 핵심입니다. 기울기가 양수라면 오른쪽이 올라가는 방향이니 왼쪽으로 가야 하기 때문입니다.

학습률을 잘못 정하면

학습률이 만드는 세 가지 결과
학습률일어나는 일그래프 모양
너무 작다걸음이 티끌만 해서 수천 번 반복해도 골짜기에 못 닿는다오차가 거의 수평으로 아주 천천히 내려간다
적당하다몇십~몇백 번 안에 오차가 최솟값에 안정적으로 도달한다처음에 뚝 떨어지고 이내 평평해진다
너무 크다골짜기를 건너뛰어 반대편 더 높은 곳에 착지하고, 이를 반복하며 튕겨 나간다오차가 위아래로 진동하다 하늘로 치솟는다

학습률이 너무 커서 오차가 오히려 무한히 커지는 현상을 발산이라고 합니다. 반대로 오차가 최솟값에 안정적으로 다가가는 것을 수렴이라고 합니다. 아래 두 번째 시뮬레이터에서 학습률을 끝까지 올려 발산을 직접 만들어 보세요.

선형 회귀의 오차 곡면은 밥그릇 모양이라 골짜기가 하나뿐이어서, 학습률만 적당하면 항상 같은 답에 도달합니다. 하지만 인공신경망(7차시)의 오차 곡면은 울퉁불퉁해 지역 최솟값에 갇힐 수 있습니다. 그래서 데이터를 조금씩 나눠 쓰는 확률적 경사 하강법, 관성을 더한 모멘텀, 학습률을 자동 조절하는 Adam 같은 방법이 개발되었습니다.

심화 상관관계는 인과관계가 아니다

선형 회귀가 “공부 시간이 1시간 늘면 점수가 7점 오른다”는 식을 내놓았다고 해서, 공부 시간이 점수를 일으켰다고 단정할 수는 없습니다. 회귀는 같이 움직이는 관계(상관)를 찾을 뿐 원인을 밝히지 않습니다.

유명한 예로 “아이스크림 판매량과 익사 사고 건수”는 강한 상관을 보입니다. 그러나 아이스크림이 사고를 일으킨 것이 아니라, 기온이라는 숨은 변수가 둘 모두를 끌어올린 것입니다. 이런 변수를 교란 변수라고 합니다.

또한 학습에 쓴 범위를 벗어난 값을 넣으면 예측이 무의미해집니다. 공부 시간 0~10시간으로 학습한 모델에 40시간을 넣으면 300점이라는 답이 나옵니다. 모델은 배운 범위 안에서만 신뢰할 수 있습니다.

코드 파이썬으로 쓴 선형 회귀와 경사 하강법

왼쪽은 경사 하강법을 식 그대로 옮긴 코드입니다. 시뮬레이터 2가 정확히 이 계산을 반복합니다.

경사 하강법 직접 구현사이킷런
 
w, b = 0.0, 0.0
lr = 0.005          # 학습률
n  = len(xs)

for step in range(500):
    # 1) 예측
    pred = [w * x + b for x in xs]
    # 2) 기울기
    gw = 2 / n * sum((p - y) * x
                     for p, y, x in zip(pred, ys, xs))
    gb = 2 / n * sum(p - y
                     for p, y in zip(pred, ys))
    # 3) 기울기 반대 방향으로 한 걸음
    w -= lr * gw
    b -= lr * gb

mse = sum((w*x + b - y) ** 2
          for x, y in zip(xs, ys)) / n
 
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

model = LinearRegression()   # 최소 제곱법
model.fit(X_train, y_train)

print("가중치 w:", model.coef_)
print("절편  b:", model.intercept_)

pred = model.predict(X_test)
print("MSE:", mean_squared_error(y_test, pred))
print("R² :", model.score(X_test, y_test))

LinearRegression은 경사 하강법이 아니라 최소 제곱법 공식으로 답을 구합니다. 그래서 반복 횟수나 학습률을 정해 줄 필요가 없습니다. 반면 데이터가 아주 클 때는 SGDRegressor처럼 경사 하강법을 쓰는 모델이 유리합니다.

사례 회귀로 예측하는 것들

전력 수요 예측 — 기온, 습도, 요일, 시간대를 넣어 몇 시에 몇 MW가 필요한지 계산합니다. 예측이 어긋나면 정전이나 낭비가 생기므로 오차 1%가 큰 비용입니다.

배달 도착 시간 — 거리, 주문 수, 날씨, 시간대로 “몇 분 뒤 도착”을 계산합니다. 여러 속성을 쓰므로 다중 회귀입니다.

중고차 가격 산정 — 연식, 주행거리, 사고 이력, 모델을 넣어 가격을 예측합니다. 이때 가중치의 부호와 크기를 보면 “주행거리 1만 km당 얼마 떨어지는가”를 사람이 직접 읽을 수 있습니다. 선형 회귀의 큰 장점인 설명 가능성입니다.

연결 다음 차시로 — 정답표가 아예 없다면
3차시와 4차시는 모두 정답이 붙은 데이터로 배우는 지도학습이었습니다. 그런데 현실의 데이터에는 정답이 없는 경우가 훨씬 많습니다. 정답 없이 “비슷한 것끼리 알아서 묶기”는 어떻게 할까요? 다음 5차시에서 비지도학습과 k-평균 군집을 배웁니다. 그리고 이 차시에서 익힌 경사 하강법은 7차시 인공신경망의 학습 원리로 그대로 다시 등장합니다.
