사진 한 장을 보고 고양이인지 아닌지 판단하는 규칙을 직접 코드로 적어 보려 합니다. “귀가 삼각형이면”, “수염이 있으면”, “털이 있으면”… 규칙을 몇 개나 적어야 할까요?

  • 고양이가 뒤돌아 앉아 있으면 귀도 수염도 보이지 않습니다.
  • 인형 고양이, 그림 고양이, 어두운 사진 속 고양이는 어떻게 할까요?

사람은 이 일을 0.1초도 안 걸려 해냅니다. 그런데 사람의 머릿속에도 “고양이 판별 규칙”이 적혀 있지는 않습니다. 대신 약 860억 개의 뉴런이 서로 신호를 주고받을 뿐입니다. 그렇다면 규칙을 적는 대신, 뉴런의 연결을 흉내 내면 어떨까요?

힌트 4차시에서 배운 것과 이어 보기
4차시에서 선 하나(y = ax + b)의 기울기와 절편을 경사 하강으로 조금씩 고쳐 데이터에 맞췄습니다. 이 차시에서는 그 “선”을 수백·수만 개 쌓아 올립니다. 고치는 방법은 놀랍게도 똑같이 경사 하강입니다.
1

뉴런을 흉내 낸 계산 한 칸

생물의 뉴런은 여러 가지에서 신호를 받아들여(가지돌기), 그 신호를 모두 합친 뒤, 합이 어떤 임곗값을 넘으면 다음 뉴런으로 전기 신호를 내보냅니다. 넘지 않으면 아무 일도 일어나지 않습니다. 1943년 매컬러와 피츠는 이 “모아서 넘으면 발사”라는 구조를 수식으로 옮겼고, 1957년 로젠블랫이 이를 학습이 가능한 형태로 만들어 퍼셉트론이라 이름 붙였습니다.

인공 뉴런은 딱 세 가지 부품으로 이루어집니다.

  • 입력 x₁, x₂, …, xₙ — 이 뉴런이 받아들이는 값(속성)
  • 가중치 w₁, w₂, …, wₙ — 각 입력이 얼마나 중요한지를 정하는 수
  • 편향 b — 전체를 위아래로 밀어 임곗값을 옮기는 수
📘 개념 — 인공 뉴런의 계산

인공 뉴런은 먼저 입력에 가중치를 곱해 모두 더하고 편향을 더해 가중합 z를 만든다.

z = w₁x₁ + w₂x₂ + ⋯ + wₙxₙ + b

그리고 이 z를 활성화 함수 f에 넣어 최종 출력을 만든다.

y = f(z)

학습이란 데이터를 보고 가중치와 편향을 고쳐 나가는 일이다. 사람이 정해 주는 것은 구조뿐이고, 값은 데이터가 정한다.

가중합을 받아 “켤지 끌지”를 정하는 함수를 활성화 함수라고 합니다. 초기 퍼셉트론은 z > 0이면 1, 아니면 0을 내보내는 계단 함수를 썼습니다. 이렇게 하면 인공 뉴런 하나가 “예/아니오”를 판단하는 가장 작은 분류기가 됩니다.

🔍 편향은 왜 필요할까?

편향이 없다면 z = w₁x₁ + w₂x₂이므로 입력이 모두 0일 때 출력이 언제나 0이 되고, 판단 기준선이 항상 원점을 지나야 합니다. 편향 b는 이 기준선을 자유롭게 옮겨 주는 역할을 합니다. 4차시의 y = ax + b에서 b가 절편이었던 것과 정확히 같은 역할입니다.

2

퍼셉트론과 논리 게이트 — 직선 하나의 한계

퍼셉트론이 정말 “판단”을 하는지 확인하는 가장 쉬운 방법은 논리 게이트를 만들어 보는 것입니다. 입력이 0과 1뿐이니 경우가 네 가지밖에 없어 손으로도 검산할 수 있습니다.

네 가지 논리 게이트의 진리표 — 입력 두 개, 출력 하나
x₁x₂ANDORNANDXOR
000010
010111
100111
111100

예를 들어 w₁ = 1, w₂ = 1, b = −1.5로 두면 (1, 1)에서만 z = 0.5 > 0이 되어 AND가 완성됩니다. 편향만 −0.5로 바꾸면 하나만 1이어도 통과하는 OR가 됩니다. 가중치를 모두 음수로 뒤집으면 NAND가 됩니다. 즉 같은 구조에 값만 바꿔 서로 다른 판단기를 만들 수 있습니다.

그런데 XOR에서 막힌다

XOR는 “두 입력이 서로 다를 때만 1”인 게이트입니다. 아무리 w₁, w₂, b를 바꿔도 퍼셉트론 하나로는 만들 수 없습니다. 이유는 기하로 보면 분명합니다. z = w₁x₁ + w₂x₂ + b = 0은 입력 평면 위의 직선 하나이고, 퍼셉트론은 이 직선을 기준으로 위쪽은 1, 아래쪽은 0으로 나눌 뿐입니다. 그런데 XOR의 정답 1인 두 점 (0,1), (1,0)과 정답 0인 두 점 (0,0), (1,1)은 대각선으로 엇갈려 놓여 있어 직선 하나로는 절대 갈라지지 않습니다.

직선(또는 고차원의 평면) 하나로 두 부류를 완전히 나눌 수 있는 성질을 선형 분리 가능성이라고 합니다. AND, OR, NAND는 선형 분리가 가능하고 XOR는 불가능합니다. 퍼셉트론 하나는 선형 분리가 가능한 문제만 풀 수 있습니다.

⚠️ 첫 번째 인공지능 겨울

1969년 민스키와 페퍼트는 저서 『퍼셉트론』에서 이 한계를 수학적으로 증명해 보였습니다. “고작 XOR도 못 푼다”는 지적은 큰 충격을 주었고, 인공지능 연구에 대한 투자가 급격히 줄어드는 이른바 첫 번째 인공지능 겨울로 이어졌습니다. 하지만 같은 책에는 층을 여러 개 쌓으면 풀린다는 사실도 이미 적혀 있었습니다. 문제는 “쌓은 망을 어떻게 학습시킬지”를 아직 몰랐다는 점이었습니다.

해결책 — 층을 쌓는다

XOR는 NAND와 OR의 결과를 다시 AND로 묶으면 만들어집니다. 즉 퍼셉트론의 출력을 다시 다른 퍼셉트론의 입력으로 넣으면 됩니다. 이렇게 층을 여러 겹으로 쌓은 구조를 다층 퍼셉트론이라 하고, 입력층과 출력층 사이에 새로 생긴 층을 은닉층이라 합니다.

결정 경계가 직선 하나. AND · OR · NAND처럼 선형 분리가 가능한 문제만 해결한다.

활성화 함수 — 어떤 모양으로 켜고 끌까

계단 함수는 뉴런을 흉내 내기엔 좋지만 학습에는 쓸 수 없습니다. 4차시에서 배웠듯 학습은 “오차를 줄이는 방향으로 조금 움직이기”, 즉 기울기를 이용합니다. 그런데 계단 함수의 기울기는 z = 0을 뺀 모든 곳에서 0이라, “어느 쪽으로 얼마나 고쳐야 하는지”를 전혀 알려 주지 못합니다. 그래서 계단을 매끄럽게 다듬은 함수들이 등장했습니다.

대표적인 활성화 함수 — 요즘 은닉층에는 ReLU, 이진 분류 출력층에는 시그모이드를 주로 쓴다
함수식출력 범위장점단점
계단 함수z > 0 ? 1 : 00 또는 1초기 퍼셉트론의 원형, 뜻이 명확기울기가 0이라 학습 불가
시그모이드1 / (1 + e⁻ᶻ)0 ~ 1확률처럼 해석 가능, 매끄럽다양 끝에서 기울기가 0에 가까워 기울기 소실
하이퍼볼릭 탄젠트tanh z−1 ~ 10을 중심으로 대칭이라 학습이 빠르다여전히 양 끝에서 기울기 소실
ReLUmax(0, z)0 ~ ∞계산이 매우 빠르고 깊은 망에서 기울기가 잘 흐른다음수 구간이 계속 0이면 뉴런이 죽는다

0 이하는 0, 양수는 그대로 내보내는 아주 단순한 함수인 ReLU는 오늘날 딥러닝 은닉층의 사실상 기본값입니다. 모양이 단순해서 계산이 빠르고, 양수 구간에서 기울기가 정확히 1이라 층이 아무리 깊어도 신호가 잘 전달됩니다.

⚠️ 자주 하는 오해

“활성화 함수는 그냥 값을 예쁘게 다듬는 장식”이라고 생각하기 쉽습니다. 그러나 활성화 함수가 없으면(또는 직선이면) 층을 100개 쌓아도 전체가 하나의 1차식으로 합쳐져 퍼셉트론 하나와 완전히 같아집니다. 층을 쌓는 일이 의미를 갖는 것은 활성화 함수가 비선형이기 때문입니다.

층을 쌓고 오차를 되돌리다

층을 쌓았으니 이제 학습시키는 방법이 필요합니다. 은닉층의 가중치는 정답과 직접 맞닿아 있지 않아서, “이 은닉 뉴런의 가중치가 얼마나 잘못되었는지”를 바로 알 수 없습니다. 이 문제를 푸는 열쇠가 1986년에 널리 알려진 오차 역전파입니다.

한 번 학습하는 과정 — 네 걸음

  1. 순전파 — 입력을 입력층에 넣고, 층마다 가중합과 활성화 함수를 계산해 출력층까지 값을 밀어 보낸다. 그 결과가 예측값이다.
  2. 손실 함수로 예측값과 실젯값의 차이를 하나의 수(손실)로 계산한다. 회귀에는 평균 제곱 오차, 이진 분류에는 이진 교차 엔트로피를 주로 쓴다.
  3. 역전파 — 출력층에서 구한 오차를 거꾸로 앞 층으로 되돌리며, 각 가중치가 손실에 얼마나 기여했는지(기울기)를 구한다.
  4. 경사 하강 — 구한 기울기의 반대 방향으로 모든 가중치와 편향을 학습률 × 기울기만큼 조금 움직인다.

이 네 걸음을 데이터 전체에 대해 한 번 돌린 것을 1 에포크라고 합니다. 에포크를 수백~수만 번 반복하면 손실이 점점 내려가고, 결정 경계가 데이터 모양에 맞게 휘어집니다.

🔍 역전파의 정체는 연쇄 법칙

역전파는 새로운 마법이 아니라 미분의 연쇄 법칙을 효율적으로 적용한 것입니다. 출력층의 오차를 δ라 하면, 앞 층의 오차는 δ에 연결 가중치를 곱해 모은 값에 그 층 활성화 함수의 기울기를 곱해 구합니다. 그래서 층이 깊어질수록 기울기가 계속 곱해지는데, 시그모이드처럼 기울기가 1보다 작은 함수를 쓰면 값이 자꾸 작아져 앞쪽 층이 거의 학습되지 않습니다. 이것이 기울기 소실 문제이고, ReLU가 널리 쓰이는 이유입니다.

딥러닝 — 왜 층을 쌓으면 좋은가

은닉층이 여러 개인 인공신경망을 심층 신경망(DNN)이라 하고, 이를 이용한 기계학습을 딥러닝이라 합니다. 층을 쌓는 것이 왜 그렇게 강력할까요? 핵심은 특징의 계층입니다.

얼굴 사진을 학습한 심층 신경망에서 층별로 뽑히는 특징 — 앞 층의 특징을 재료로 뒤 층이 더 큰 특징을 만든다
층뽑아내는 특징비유
1층밝기가 갑자기 바뀌는 짧은 선분, 점, 색 얼룩글자의 획
2층선분이 모여 만드는 모서리, 곡선, 무늬낱글자
3층눈, 코, 입 같은 부분 모양낱말
4층 이상부분들의 배치 = 얼굴 전체, 사람의 신원문장

기존 기계학습에서는 “어떤 속성을 넣을지”를 사람이 정해 주어야 했습니다(2차시의 속성 추출). 딥러닝은 이 특징 추출까지 스스로 학습합니다. 대신 값을 정해야 할 가중치가 수백만~수천억 개로 늘어나므로, 아주 많은 데이터와 강력한 계산 장치(GPU)가 필요합니다. 딥러닝이 2010년대에 갑자기 꽃핀 이유가 바로 데이터·계산력·알고리즘 세 가지가 동시에 갖춰졌기 때문입니다.

✅ 정리

인공신경망은 가중치와 편향을 가진 인공 뉴런을 층으로 연결한 모델이고, 학습은 순전파 → 손실 계산 → 역전파 → 경사 하강의 반복이다. 은닉층을 여러 개 쌓아 특징을 계층적으로 뽑는 것이 딥러닝이다.

이미지를 보는 눈 — 합성곱 신경망

가로세로 100픽셀짜리 컬러 사진 한 장은 값이 100 × 100 × 3 = 30,000개입니다. 이것을 한 줄로 펴서 다층 퍼셉트론에 넣으면 첫 은닉층 뉴런 하나마다 가중치가 3만 개씩 필요합니다. 게다가 한 줄로 펴는 순간 “옆 픽셀과 붙어 있다”는 정보가 사라집니다. 고양이가 사진 왼쪽에 있을 때와 오른쪽에 있을 때를 완전히 다른 입력으로 보게 되는 것도 문제입니다.

이를 해결한 구조가 합성곱 신경망(CNN)입니다. 핵심 아이디어는 “작은 필터(커널) 하나를 이미지 전체에 돌려쓰기”입니다.

📘 개념 — 합성곱 연산

3×3 크기의 필터(커널)를 이미지 왼쪽 위에 겹쳐 놓고, 겹친 9개 픽셀값과 필터의 9개 가중치를 각각 곱해 모두 더한다. 이 값 하나가 결과 이미지의 픽셀 하나가 된다. 필터를 한 칸 옆으로 옮겨 같은 계산을 반복하며 이미지 전체를 훑으면 결과 이미지가 완성되는데, 이것을 특성 맵(feature map, 특징 지도)이라 한다. 이 연산이 합성곱이다.

중요한 것은 필터의 9개 값을 사람이 정하지 않는다는 점입니다. CNN은 이 값들을 가중치로 보고 역전파로 학습합니다. 학습이 끝나면 1층 필터들은 대체로 “세로 경계”, “가로 경계”, “대각선”처럼 단순한 무늬 검출기가 되고, 뒤쪽 층의 필터는 그 결과를 다시 조합해 “바퀴”, “눈”처럼 더 큰 부품을 찾아냅니다. 앞서 본 특징의 계층이 그림으로 확인되는 셈입니다.

완전 연결 층

합성곱·풀링을 여러 번 거쳐 남은 특징들을 한 줄로 펴서 넣는다. 여기서 실제 분류가 이루어진다.

여러 칸 중 대푯값만 남겨 특성 맵의 크기를 줄이는 층을 풀링 층이라 합니다. 전형적인 CNN은 합성곱 → 풀링 → 합성곱 → 풀링 → ⋯ → 완전 연결 순서로 구성됩니다.

순서가 있는 데이터, 그리고 활용 분야

이미지에는 “옆에 붙어 있다”는 구조가 있었습니다. 그런데 말·글·주가·기온처럼 순서가 중요한 데이터도 있습니다. “나는 밥을 먹었다”와 “밥을 나는 먹었다”는 낱말이 같아도 뜻이 다릅니다. 순환 신경망(RNN)은 이런 데이터를 위해, 출력의 일부를 다시 자기 입력으로 되돌려 앞에서 본 내용을 기억합니다. 하지만 문장이 길어지면 앞부분의 기억이 흐려지는 약점이 있었습니다.

2017년에 발표된 트랜스포머는 순환 구조를 버리고 어텐션이라는 방법을 씁니다. 어텐션은 어떤 낱말을 해석할 때 문장 안의 모든 낱말과의 관련도를 한꺼번에 계산해, 관련이 큰 낱말에 더 큰 비중을 둡니다. “그 사과는 맛있었다”에서 ‘사과’를 과일로 볼지 용서로 볼지는 ‘맛있었다’와의 관련도가 알려 줍니다. 순서대로 처리하지 않으니 병렬 계산이 쉬워 아주 큰 모델을 훈련할 수 있게 되었고, 이것이 오늘날 거대 언어 모델과 생성형 인공지능의 바탕이 되었습니다.

심화 왜 은닉 뉴런이 2개면 XOR가 되는가

은닉 뉴런 두 개가 각각 직선 하나를 담당한다고 생각해 봅시다. 첫 번째 뉴런은 x₁ + x₂ − 0.5 > 0(= OR), 두 번째 뉴런은 −x₁ − x₂ + 1.5 > 0(= NAND)을 계산합니다. 네 점의 은닉층 출력은 이렇게 바뀝니다.

입력h₁ (OR)h₂ (NAND)XOR 정답
(0, 0)010
(0, 1)111
(1, 0)111
(1, 1)100

새로운 좌표 (h₁, h₂)에서 보면 정답 1인 두 점은 (1, 1) 한 곳으로 겹쳐 버리고, 정답 0인 두 점은 (0, 1)과 (1, 0)에 놓입니다. 이제 h₁ + h₂ − 1.5 > 0(= AND)이라는 직선 하나로 깔끔하게 나뉩니다.

즉 은닉층은 입력 공간을 접어서(변형해서) 선형 분리가 가능한 새 공간으로 옮겨 주는 일을 합니다. “층을 쌓으면 복잡한 경계를 만든다”는 말의 정확한 뜻이 바로 이것입니다.

코드 파이썬으로 쓴 다층 퍼셉트론과 CNN

텐서플로·케라스에서는 층을 순서대로 쌓기만 하면 순전파와 역전파를 자동으로 처리해 줍니다. 우리가 정하는 것은 구조·활성화 함수·손실 함수·학습률입니다.

다층 퍼셉트론 (표 데이터 분류)합성곱 신경망 (이미지 분류)
 
model = Sequential([
  # 은닉층 32개, 활성화 함수 ReLU
  Dense(32, activation='relu',
        input_shape=(2,)),
  Dense(16, activation='relu'),
  # 출력층: 이진 분류 → 시그모이드
  Dense(1, activation='sigmoid')
])
model.compile(
  optimizer='adam',
  loss='binary_crossentropy',
  metrics=['accuracy'])
model.fit(X, y, epochs=300)
 
model = Sequential([
  # 3x3 필터 32개를 학습한다
  Conv2D(32, (3, 3), activation='relu',
         input_shape=(32, 32, 1)),
  MaxPooling2D((2, 2)),   # 풀링
  Conv2D(64, (3, 3), activation='relu'),
  MaxPooling2D((2, 2)),
  Flatten(),              # 한 줄로 펴기
  Dense(64, activation='relu'),
  # 10개 분류 → 소프트맥스
  Dense(10, activation='softmax')
])

Conv2D(32, (3, 3))은 “3×3 필터 32종류를 학습하겠다”는 뜻입니다. 시뮬레이터 ③에서 우리가 손으로 넣은 9개 값이, 실제로는 이렇게 32벌씩 학습되는 가중치인 셈입니다.

사례 필터 하나가 만든 실생활의 변화
  • 의료 영상 — 안저 사진에서 당뇨망막병증을 찾아내는 CNN 모델이 안과 전문의와 비슷한 수준의 판별력을 보였습니다. 다만 최종 진단은 사람이 합니다.
  • 농업 — 스마트폰으로 잎을 찍으면 병해충을 알려 주는 앱은 잎맥과 반점의 무늬를 필터가 찾아내는 원리입니다.
  • 문화유산 — 훼손된 벽화나 오래된 필름을 복원할 때, 주변 무늬를 학습한 모델이 빈 부분을 채워 넣습니다.
  • 접근성 — 사진의 내용을 문장으로 설명해 주는 기능은 CNN(보기)과 트랜스포머(말하기)를 이어 붙여 만듭니다.

공통점은 모두 사람이 규칙을 적지 않았다는 것입니다. 규칙 대신 데이터를 주었을 뿐입니다.

연결 2단원을 마무리하며

1차시에서 “규칙을 짜지 않고 가르친다”로 출발해, 데이터를 다듬고(2차시), 분류와 회귀와 군집을 배우고(3~5차시), 성능을 평가하는 법을 익힌 뒤(6차시), 이번 차시에서 층을 쌓아 특징까지 스스로 배우는 딥러닝에 이르렀습니다.

여기서 배운 과대적합과 혼동 행렬은 딥러닝에서도 그대로 쓰입니다. 시뮬레이터 ②에서 은닉층을 2층, 뉴런을 8개로 두고 나선 데이터를 아주 오래 학습시키면, 결정 경계가 점 하나하나를 감싸듯 구불구불해지는 것을 볼 수 있습니다. 훈련 데이터는 100% 맞히지만 새 점은 틀릴 가능성이 커진 상태 — 바로 딥러닝에서의 과대적합입니다. 단원 마무리에서 이 개념들을 한 장의 지도로 묶어 정리합니다.
