## 학습자용 기능

- **✏️ 빈칸 채우기 모드** — 본문 핵심 용어가 입력칸으로 바뀝니다. 힌트와 즉시 채점 제공.
- **🕹️ 시뮬레이터** — 하드코딩된 애니메이션이 아니라 **브라우저에서 실제로 계산**합니다. 신경망은 정말 학습하고, A\*는 정말 탐색하며, 편향 실험실은 정말 모델을 다시 학습시킵니다.
- **📝 확인 문제** — 객관식 · 복수 정답 · O/X · 단답형 · 순서 배열 · 짝 맞추기. 즉시 해설.
- **✍️ 활동 기록** — 활동지 역할. 자동 저장되고 포트폴리오에 모입니다.
- **📊 자가평가** — 단원 마무리에서 성취기준별 A~E 자기 점검, 부족한 차시로 바로 이동.
- **📁 내 학습 포트폴리오** — 진도·활동기록·자가평가를 모아 인쇄하거나 파일로 내보내기.

## 기술 사항

- **의존성 0** — CDN · 외부 폰트 · 외부 이미지 · 프레임워크를 전혀 쓰지 않습니다. 오프라인에서 완전히 동작합니다.
- 고전 `<script>` 방식이라 `file://`로 열어도 됩니다 (`index.html` 더블클릭).
- 그림은 전부 인라인 SVG 또는 `<canvas>`로 직접 그립니다.
- 밝은/어두운 화면 지원, 인쇄 서식 별도 정의.
- 학습 기록은 **학생 브라우저의 localStorage에만** 저장되며 서버로 전송되지 않습니다.

### 폴더 구조

```
├── index.html          전체 목차
├── portfolio.html      내 학습 포트폴리오
├── assets/
│   ├── css/textbook.css
│   └── js/  data.js (교육과정 데이터) · core.js (공통 엔진)
├── area1/ ~ area4/     영역별 lesson01~NN.html + closing.html
├── _selftest.html      30쪽 자동 점검 도구 (수업용 아님)
└── 읽어보기.md          교사용 안내
```

내용 수정은 각 `lessonNN.html`만 고치면 되고, 차시 목록·성취기준은 `assets/js/data.js`에서 관리합니다.
수정 후 `_selftest.html`을 열면 30쪽 전체를 자동 점검합니다.
